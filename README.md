# صيدليتي

لوحة لصاحب الصيدلية: إيه اللي يتطلب، إيه اللي قرب ينتهي أو راكد، عروض جاهزة للواتساب، حاسبة المكسب الصافي بعد الضرايب والمصاريف، وتقسيم البضاعة والمكسب على الشركاء.

- بيانات الصيدلية بتتقري **على جهاز المستخدم بس** (ملفات Excel/CSV من برنامج الصيدلية)، ومش بتترفع على سيرفر.
- كل الحسابات في `src/core.js` وعليها tests في `test/`.
- نسب الضريبة في النظام المبسط من قانون 6 لسنة 2025؛ أهلية الصيدلية للنظام ده لازم تتأكد من محاسب.

```bash
npm test      # الحسابات
npm run dev   # http://localhost:3000
```

## الوصلة (Connector) لبرنامج الصيدلية

برنامج الصيدلية بيخزّن بياناته في SQL Server. الخطوة الأولى بتشتغل على جهاز الويندوز:

1. ثبّت SQL Server 2022 Express.
2. شغّل:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\connector\restore-and-discover.ps1 -Backup "C:\Users\<you>\Downloads\<backup>.gen"
   ```
3. السكريبت بيرجّع نسخة منفصلة اسمها `SaydalitiCopy` (من غير ما يلمس قاعدة بيانات الصيدلية الأصلية)، ويطلّع `schema.json` فيه أسماء الجداول والأعمدة وعدد الصفوف بس، من غير أي بيانات زباين أو مبيعات.

4. انسخ `connector/mapping.example.json` لـ `mapping.json` واكتب فيه أسماء الجداول والأعمدة من `schema.json`.
5. شغّل `connector/export.ps1`، فيطلع `data.json`: الأصناف، والمخزون بالتشغيلة والصلاحية، والمبيعات متجمّعة لكل صنف في اليوم. من غير أي بيانات زباين.
6. تقرير الصبح: `node scripts/morning.js connector/data.json "اسم الصيدلية"`. ونفس الملف بيترفع في اللوحة.

### تشغيل يومي أوتوماتيك
1. من اللوحة (صاحب الصيدلية): الإعدادات ← «الوصلة على جهاز الكاشير» ← «اعمل كود للوصلة»، واحفظ اللي يظهر في `connector/connector.json` على جهاز الكاشير.
2. في `connector.json` اكتب اسم قاعدة بيانات برنامج الصيدلية (`database`)، و`sqlUser`/`sqlPassword` لو البرنامج بيستخدم حساب SQL.
3. `powershell -ExecutionPolicy Bypass -File .\connector\install-schedule.ps1 -At 07:00`
   كل يوم: `export.ps1` (قراءة فقط، `ApplicationIntent=ReadOnly`) ثم `upload.ps1`، والسجل في `connector/connector.log`.
- الكود بيتحفظ في قاعدة البيانات مشفّر (SHA-256)، وبيقدر يرفع نسخة بس، ومش بيقرا أي حاجة. عمل كود جديد بيلغي القديم.

## النشر (Vercel + Supabase)

- قاعدة البيانات: `supabase/migrations/` (الصيدليات، الأعضاء، الموظفين، الحضور، أكواد الدعوة). كل الصلاحيات بتتأكد جوه قاعدة البيانات (RLS).
- متغيرين في Vercel (Project → Settings → Environment Variables): `SUPABASE_URL` و`SUPABASE_PUBLISHABLE_KEY`.
- من غيرهم، صفحة الحضور بتشتغل كتجربة على الجهاز بس.
- الأدوار: صاحب الصيدلية (كل حاجة)، شريك (التقرير بس)، جهاز الصيدلية (التسجيل بالكود بس). الشريك والجهاز بيدخلوا بكود دعوة من صاحب الصيدلية.
