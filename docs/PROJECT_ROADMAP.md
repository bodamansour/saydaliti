# صيدليتي — خارطة الطريق

آخر مراجعة: 2026-10-30. الخطة مبنية على الفجوات الموجودة في الكود الحالي، مش على قائمة الرغبات وحدها. لا تعاد كتابة الميزات التي تعمل.

## أولوية 0 — ضمان سلامة النسخة الحالية

1. تثبيت إصلاحات اختبارات Windows الحالية، وتشغيل اختبارات الواجهة وWorker في CI.
2. تأكيد ذرّية المرتجعات المتزامنة في CI. أُضيف إدخال SQL مشروط واختبار API متزامن بلا ترحيل قاعدة؛ تشغيل الاختبار المحلي تعذر لأن إعداد D1 عبر Wrangler أعاد `fetch failed`.
3. معالجة تنبيه `xlsx@0.18.5` عالي الخطورة. تقييم بديل يحافظ على قراءة ملفات Excel وكتابة المصنفات قبل تغيير المكتبة، وفحص تبعيات Wrangler التطويرية منفصلة عن تبعيات التشغيل.
4. توثيق تجربة استعادة دورية لنسخة احتياطية في صيدلية اختبارية، من غير لمس بيانات الإنتاج.

## أولوية 1 — صلاحيات الفروع والحسابات

- تحديد نطاق وصول الموظفين على فرع واحد أو عدة فروع. هذا يمس الصلاحيات وقاعدة البيانات؛ قبل تنفيذه تُقارن بدائل جدول ربط للفروع مقابل نطاقات محفوظة للعضوية، ثم يُختار تصميم وتُكتب اختبارات تمنع عبور الفروع.
- إضافة استرجاع كلمة مرور بالبريد وMFA بعد اختيار خدمة وهوية الحساب وآلية الاسترداد.
- استكمال نافذة تنبيه الصلاحية القابلة للضبط.

## أولوية 2 — متابعة المال والتكلفة

- إضافة شاشة تاريخ تكلفة الصنف.
- تعريف معنى «رصيد الخزينة» ومصادره قبل عرضه كرقم مجمع؛ فصل درج الورديات عن النقدية خارج الدرج.
- إضافة ضريبة قابلة للتهيئة عندما تتحدد قواعد المنتج والسوق المستهدف.

## أولوية 3 — الاستدامة التجارية والمنصات

- ربط دفع إلكتروني بعد اختيار بوابة وتوفير حساب التاجر ومفاتيح الاختبار والإنتاج.
- إضافة مؤشرات استخدام مفيدة في Super Admin مع حدود واضحة للوصول إلى بيانات الصيدليات.
- إضافة إشعارات Push أصلية للموبايل فقط بعد خدمة الإرسال وموافقة المستخدم وإعدادات Android/iOS.
- تأكيد خطة Cloudflare المدفوعة ومراقبة الأداء قبل التوسع لعملاء إنتاجيين.

## مؤجل بقرار مسجل

- الكتابة أو الجرد مباشرة في قاعدة برنامج المتحدة: مؤجل؛ يظل ملف التصحيح الحالي آلية يراجعها المستخدم.
- الفاتورة الإلكترونية: مؤجلة حسب قرار صاحب المشروع، ولا يُدّعى الامتثال قبل تنفيذ واعتماد المتطلبات الرسمية.

## شروط إغلاق كل بند

كل ميزة تُغلق بعد كود يعمل، وتحقق صلاحيات ومعالجة أخطاء، واختبار يغطّي المسار الأساسي والحالات الحدية، وتحديث [`FEATURES_STATUS.md`](FEATURES_STATUS.md) و[`TESTING_REPORT.md`](TESTING_REPORT.md). أي تغيير بيانات أو صلاحيات يسبقه توثيق البدائل وخطة التراجع.
