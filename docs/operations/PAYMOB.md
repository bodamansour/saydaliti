# دفع الاشتراك أونلاين (Paymob)

صاحب الصيدلية بيدوس «ادفع شهر أونلاين» أو «ادفع سنة» من شريط الاشتراك أو من الصفحة المقفولة، فبتفتح صفحة الدفع بتاعة Paymob (كارت أو محفظة). أول ما Paymob يبعت إن الدفع تم، الاشتراك بيتمد لوحده.

## إزاي بيشتغل

- **المبلغ:** السيرفر بيحسبه، والصفحة ملهاش دعوة بيه (`payAmount` في `src/subscription.js`). لو الصيدلية على خطة ليها سعر، بياخد سعر الخطة، والسنة بسعر السنة لو متحدد. غير كده بياخد السعر الشهري (السعر الخاص بالصيدلية، أو الأساسي + الفروع) مضروب في عدد الشهور.
- **كل دفعة صف في جدول `payments`** (تحديث 0018)، بيبدأ `pending`.
- **Paymob بيبعت رسالة لـ `/api/pay/webhook?hmac=…`.** السيرفر بيقبلها بس لو:
  - توقيع HMAC-SHA512 صح بمفتاح `PAYMOB_HMAC`.
  - الدفع نجح فعلاً ومش معلّق.
  - العملة جنيه.
  - المبلغ هو نفس اللي اتطلب.
- **الدفعة بتتحسب مرة واحدة بس:** الصف بيتحول لـ `paid` مرة واحدة، ولو نفس الرسالة اتبعتت تاني مبيتغيرش حاجة.
- **الشهور بتتحسب من:**
  - آخر يوم في المدفوع، لو لسه مخلصش.
  - آخر يوم في التجربة المجانية، لو الصيدلية لسه في التجربة.
  - النهارده، لو مفيش ولا ده ولا ده.
- الصيدلية الموقوفة بتفضل موقوفة، والمدير هو اللي يقرر. الشهور برضه بتتضاف.
- على staging أي طلب لبرّه مقفول، والمفاتيح دي ممنوعة هناك.

## التفعيل (صاحب المشروع)

1. **افتح حساب تاجر على Paymob** (accept.paymob.com). ابدأ بوضع التجربة (Test mode).
2. **من Developers ← API Keys** هات:
   - **Secret key** ← `PAYMOB_SECRET_KEY`
   - **Public key** ← `PAYMOB_PUBLIC_KEY`
3. **من Developers ← Payment Integrations** هات أرقام الـ integration (الكارت والمحفظة) ← `PAYMOB_INTEGRATION_IDS`. حطهم مفصولين بفاصلة: `123456, 654321`.
4. **من Settings ← Account Info** هات HMAC ← `PAYMOB_HMAC`.
5. **حط الأربعة كأسرار على Worker `tablix`**، بأمر لكل واحد:
   ```
   npx wrangler secret put PAYMOB_SECRET_KEY
   ```
   ومتكتبهمش في أي ملف.
6. **في الـ integration، اكتب الـ callback:**
   - Transaction processed: `https://tablix.tablixpharma.workers.dev/api/pay/webhook`
   - Transaction response: `https://tablix.tablixpharma.workers.dev/?paid=1`
7. **حط سعر الاشتراك من صفحة الإدارة**، عشان السيرفر يرفض الدفع لو السعر صفر.
8. **جرّب بكارت التجربة** بتاع Paymob. اتأكد إن `paid_until` اتغير في صفحة الإدارة، وبعدها بدّل لمفاتيح الإنتاج.
