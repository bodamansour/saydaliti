# الدخول بجوجل

على صفحة الدخول بيظهر زرار «ادخل بحساب جوجل»، وفي صفحة الحساب الجديد «اعمل حساب بجوجل». الزرار بيظهر بس لما السيرفر يبقى عليه المفتاحين.

## إزاي بيشتغل

- الطريقة هي OpenID Connect بكود ومعاه PKCE (`worker/src/google.js`). الـ state والـ verifier بيتحطوا في cookie قصيرة HttpOnly، فلو الرجوع من جوجل جه من متصفح تاني أو من موقع تاني، محدش بيدخل.
- السيرفر بياخد الـ ID token من جوجل مباشرة بالمفتاح السري، وبيتأكد من:
  - إن الـ token معمول للأبلكيشن بتاعنا (`aud`)
  - إنه جاي من جوجل (`iss`)
  - إن وقته مخلصش
  - إن الإيميل متأكَّد منه
- **لو الإيميل عليه حساب:** بيدخل الحساب ده.
- **لو الإيميل جديد:** بيتعمل حساب جديد من غير كلمة سر، بنفس حد الحسابات الجديدة اللي بيتعمل بالإيميل وكلمة السر. لو صاحبه عايز كلمة سر، يعملها من «نسيت كلمة السر».
- **لو الحساب عليه تحقق بخطوتين:** الدخول بجوجل بيترفض، ولازم يدخل بكلمة السر والكود.
- برنامج الويندوز مفيهوش الزرار، لأن جوجل بيرفض صفحة الدخول بتاعته جوه شباك الأبلكيشن.
- على staging، أي طلب لبرّه مقفول، والمفتاحين دول ممنوعين هناك.

## التفعيل (صاحب المشروع)

1. افتح [Google Cloud Console](https://console.cloud.google.com) واعمل مشروع.
2. من **APIs & Services ← OAuth consent screen**:
   - النوع External
   - اسم الأبلكيشن Tablix Pharma
   - إيميل الدعم
   - الـ scopes: `openid` و`email` بس
3. من **Credentials ← Create credentials ← OAuth client ID**:
   - النوع: Web application
   - **Authorized redirect URIs:** `https://tablix.tablixpharma.workers.dev/api/auth/google/callback`. ولما يبقى فيه دومين، ضيف عنوانه كمان.
4. حط الاتنين كأسرار على Worker `tablix`، ومتكتبهمش في أي ملف:
   ```
   npx wrangler secret put GOOGLE_CLIENT_ID
   npx wrangler secret put GOOGLE_CLIENT_SECRET
   ```
5. انشر، وجرّب من صفحة الدخول.
6. لحد ما تعمل **Publish app** في شاشة الموافقة، الدخول بيشتغل بس للإيميلات اللي ضفتها في Test users.
