## حدود التحقق

- Chromium في بيئة العمل يلغي كل تنزيلات المتصفح، حتى في صفحة محلية بسيطة. لذلك اختبارات التصدير تتحقق من محتوى Blob الذي تنتجه الواجهة، ولا تثبت أن نافذة تنزيل نظام التشغيل تحفظ الملف بنجاح على جهاز صيدلية حقيقي.
- إعداد Wrangler/D1 المحلي على Windows أعاد `fetch failed` في التشغيل السابق. GitHub Actions #106 شغّل Worker بعد إصلاح المرتجعات بنجاح، بما فيه اختبار التزامن، باستخدام D1 وR2 محليتين لا بيانات إنتاج. تأكدت الترقية إلى Wrangler `4.156.0` في التشغيل نفسه.
- اختبار Worker لنطاق الفروع الجديد لم يعمل محليًا بعد: Wrangler على Windows أعاد `fetch failed` قبل تشغيل D1. يجب انتظار CI الذي يطبق ترحيل 0010 ويشغّل اختبار API قبل اعتبار الميزة متحققة.
- اختبار Electron المحلي لم يفتح البرنامج بسبب ACL بيئة Windows المقيدة؛ نجح بناء المثبت وفحص smoke وتشغيل البيانات دون اتصال على Windows في GitHub Actions #80.
- CI هو المسار الذي يشغّل SQL Server حقيقيًا لاختبار وصلة United؛ لم يُشغّل SQL Server محليًا في هذه الجلسة.
- لا يوجد اختبار استعادة مجدول على نسخة إنتاجية، ولا يُفترض وجوده.
