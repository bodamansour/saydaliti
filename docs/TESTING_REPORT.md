## حدود التحقق

- Chromium في بيئة العمل يلغي كل تنزيلات المتصفح، حتى في صفحة محلية بسيطة. لذلك اختبارات التصدير تتحقق من محتوى Blob الذي تنتجه الواجهة، ولا تثبت أن نافذة تنزيل نظام التشغيل تحفظ الملف بنجاح على جهاز صيدلية حقيقي.
- إعداد Wrangler/D1 المحلي على Windows أعاد `fetch failed`، لكن CI #103 شغّل Worker بعد التغيير بنجاح، بما فيه اختبار التزامن. يستخدم CI قاعدة D1 وR2 محليتين، لا بيانات إنتاج.
- CI هو المسار الذي يشغّل SQL Server حقيقيًا لاختبار وصلة United؛ لم يُشغّل SQL Server محليًا في هذه الجلسة.
- لا يوجد اختبار استعادة مجدول على نسخة إنتاجية، ولا يُفترض وجوده.
