## حدود التحقق

- Chromium في بيئة العمل يلغي كل تنزيلات المتصفح، حتى في صفحة محلية بسيطة. لذلك اختبارات التصدير تتحقق من محتوى Blob الذي تنتجه الواجهة، ولا تثبت أن نافذة تنزيل نظام التشغيل تحفظ الملف بنجاح على جهاز صيدلية حقيقي.
- إعداد Wrangler/D1 المحلي على Windows أعاد `fetch failed` في التشغيل السابق. CI #105 شغّل Worker بعد إصلاح المرتجعات بنجاح، بما فيه اختبار التزامن. يستخدم CI قاعدة D1 وR2 محليتين، لا بيانات إنتاج. تحديث Wrangler `4.156.0` يحتاج إعادة تأكيد على CI.
- اختبار Electron المحلي لم يفتح البرنامج بسبب ACL بيئة Windows المقيدة؛ نجاح `npm run app` يثبت تجميع الملفات فقط. ينتظر smoke اختبار GitHub Actions بعد تغيير Electron.
- CI هو المسار الذي يشغّل SQL Server حقيقيًا لاختبار وصلة United؛ لم يُشغّل SQL Server محليًا في هذه الجلسة.
- لا يوجد اختبار استعادة مجدول على نسخة إنتاجية، ولا يُفترض وجوده.
